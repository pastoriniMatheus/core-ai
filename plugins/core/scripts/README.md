# Scripts dentro do plugin

Cópias-espelho de `/scripts`, para que os comandos funcionem numa instalação por
plugin — que é o caminho principal e não carrega a raiz do repositório.

**Não edite aqui.** A fonte é `/scripts`; `node scripts/sincronizar-plugin.mjs`
copia, e `tests/docs.test.mjs` falha se as duas versões divergirem.
